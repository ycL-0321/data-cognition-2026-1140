## 质量措施

- 使用 `requests.Session` 复用连接。
- 每次请求设置超时和自动重试。
- 网络请求间隔为 0.1 秒，降低接口压力。
- 原始 JSON 先写入临时文件，成功后再替换正式缓存。
- 连续多次失败后自动停止，避免断网时继续无效请求。
- 缓存已下载资源，网络恢复后可从断点继续。
- 使用 `validate_data.py` 检查字段、行数、地区、重复编号、数据类型和关系完整性。

## 已知限制

- 地区归类使用物种首次出现的世代，不代表该物种在当前地区生态中的全部分布。
- 地区形态依据形态名称识别，特殊换装形态已排除。
- 数据量以采集当天 PokeAPI 返回的物种数量为准。
- 后续新增世代时，需要重新运行采集和验证脚本。
