# 实验二报告：九地区生物图鉴数据采集与清洗

## 一、实验目的

使用公开数据接口完成图鉴数据采集，形成可复现、可检查、可继续分析的结构化数据集，为实验三的地区差异可视化提供数据基础。

## 二、数据来源

- 数据源：PokeAPI API v2
- 官网：`https://pokeapi.co/`
- 接口文档：`https://pokeapi.co/docs/v2`
- 认证方式：不需要 API Key

主要使用以下接口：

| 接口 | 用途 |
|---|---|
| `/pokemon-species` | 获取物种索引、中文名、世代、传说状态 |
| `/pokemon` | 获取默认形态、属性、能力值、身高和体重 |
| `/generation` | 支撑世代与地区映射 |

## 三、采集流程

```text
物种索引
  -> 物种详情
  -> 默认形态详情
  -> 地区形态详情
  -> 原始 JSON 缓存
  -> CSV 清洗
  -> 汇总表
  -> 自动质量校验
```

## 四、数据处理规则

1. 每个基础物种保留一条记录。
2. 物种首次出现的世代映射为九个主要地区。
3. 双属性物种分别保存第一属性和第二属性。
4. 六项能力值相加得到总种族值。
5. 阿罗拉、伽勒尔、洗翠和帕底亚形态单独保存。
6. 地区形态不重复计入新增物种数量。
7. 中文名优先使用 `zh-hans`，其次使用 `zh-hant`，最后回退英文名。
8. 特殊帽子、图腾等非地区形态不计入地区形态表。

## 六、数据质量

数据检查覆盖以下内容：

- 必需数据文件是否存在。
- CSV 必需字段是否齐全。
- 物种行数是否与质量报告一致。
- 物种编号是否重复。
- 九个地区是否全部覆盖。
- 核心字段是否存在缺失值。
- 属性名称是否属于标准属性集合。
- 能力值是否为有效数值。
- 地区形态是否能关联到基础物种。
- 原始缓存是否存在。

运行命令：

```powershell
.\.venv\Scripts\python.exe .\validate_data.py
```

校验结果写入：

```text
data/validation_report.json
```
